# PDF Studio Official Documentation & User Guide

Welcome to the official documentation for **PDF Studio** — the high-performance, privacy-first document designer and PDF generation suite for Android.

---

## 📚 Guide Categories

1. **[Batch Generation & Mail Merge (CSV Automation)](batch_and_csv.md)**
   - High-speed automated batch PDF generation from CSV datasets.
   - Multi-row invoice grouping (merging multiple rows sharing `invoice_no` into one document with a structured table).
   - Filename pattern tokens (`Invoice_{invoice_number}_{client_name}.pdf`).
   - Exporting as individual PDFs, a combined multi-page document, or a `.zip` archive.

2. **[Formula Engine & Calculations](formula_engine.md)**
   - Dynamic spreadsheet formulas: `=SUM(C1:C10)`, `=AVG(...)`, `=MIN(...)`, `=MAX(...)`, `=COUNT(...)`.
   - Arithmetic operations: `=A1 * B1 * 1.18` (tax / discount calculation).
   - Real-time evaluation across dynamic tables and text components.

3. **[JSON Template Specification & Automation](json_templates.md)**
   - Full JSON document and template schema definition.
   - Structured JSON batch ingestion with nested line items and scalar inheritance.
   - Template inputs (`TEXT`, `NUMBER`, `DATE`, `DROPDOWN`, `CHECKBOX`, `IMAGE`, `SIGNATURE`, `TABLE`).

4. **[Design Elements, Shapes & Visual Components](elements_and_shapes.md)**
   - Typography, Headings, and dynamic auto-wrapping Paragraphs.
   - Vector shapes: Bézier curves, sinusoidal waves, stars, polygons, arrows, and diagonal cuts.
   - Interactive charts: Bar, Line, Pie, and Donut allocation charts.
   - Botanical ornaments, gold filigree borders, and digital signatures.
